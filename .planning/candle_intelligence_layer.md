## 1. What We Are Building

A new sub-package inside the existing **L4 Intelligence layer** (Athena) that:

1. Fetches real OHLCV candle data (5-min candles, last 50 candles) per symbol via yfinance
2. Computes candle-pattern features (body size, wick ratios, engulfing, doji, momentum)
3. Runs a pretrained scikit-learn RandomForest model → outputs (signal, probability)
4. Feeds the pretrained signal + candle summary to **Ollama** as a reviewer prompt
5. Ollama either confirms, overrides, or abstains → final fused `Decision` returned
6. Self-throttles to **10-minute TTL per symbol** — no external scheduler needed
7. Outputs a standard `Decision` object — plugs into existing `DecisionEvent` → `RiskEngine` pipeline with zero changes to any other layer

## 2. Conflict Analysis — Existing Codebase

### 2.1 What already exists that we must NOT duplicate or break

| Existing component | What it does | Our constraint |
|---|---|---|
| `OllamaClient` (`intelligence/agent/ollama_client.py`) | `complete(prompt) -> str` via Ollama `/api/generate` | **Reuse directly** — do NOT create another HTTP client for Ollama |
| `OllamaStrategy` (`intelligence/strategies/ollama_strategy.py`) | Full strategy using `OllamaClient`, has `evaluate()` and `evaluate_with_context()` | **Do NOT subclass or modify** — our layer calls `OllamaClient` directly with a different prompt |
| `AtlasStrategy` (`intelligence/strategies/atlas_strategy.py`) | 6-step ATLAS with Groq→Ollama fallback, uses `urllib.request` directly | **Do NOT touch** — completely separate strategy |
| `FeatureEngineer` (`data/features/feature_engineer.py`) | Computes 25 features from `MarketTick` list | **Do NOT use for candles** — it works on `MarketTick` objects, not OHLCV candles. Our `CandleFeatures` is separate and candle-specific |
| `YFinanceProvider` (`data/providers/yfinance_provider.py`) | Fetches latest price tick via `yf.download`, TTL cache | **Do NOT reuse** — it fetches single price ticks. We need OHLCV candle history. Our `CandleFetcher` uses `yf.Ticker.history()` which is a different yfinance API call |
| `Decision` (`intelligence/models/decision.py`) | Frozen dataclass, `symbol/action/confidence/rationale/strategy_id` | **Return this exact type** — no new decision model |
| `DecisionEvent` (`intelligence/events/decision_event.py`) | Frozen dataclass extending `BaseEvent` | **Publish this exact type** — no new event type |
| `IStrategy` (`intelligence/strategies/i_strategy.py`) | Protocol: `evaluate(FeatureVector) -> Decision` | **Do NOT implement** — `CandleStrategy.evaluate()` takes a `symbol: str`, not a `FeatureVector`. It is NOT an `IStrategy`. It is a standalone orchestrator. |
| `RiskEngine` (`execution/risk/risk_engine.py`) | Gates decisions, sizes orders | **Zero changes** — our `Decision` flows through it unchanged |
| `run_hour.py` (root) | Main trading loop | **Minimal addition** — one `if` block to call `CandleStrategy` every 10 min |

### 2.2 Architecture rules confirmed

- `intelligence/candle/` imports from: `intelligence/agent/ollama_client.py`, `intelligence/models/decision.py` — both same layer ✅
- `intelligence/candle/` imports from: `data/models/market_tick.py` — data layer, allowed (L4 can read L3 models) ✅
- `intelligence/candle/` does NOT import from: `execution`, `analytics`, `dashboard`, `communication` ✅
- `CandleFetcher` uses `yfinance` directly — does NOT import `YFinanceProvider` (different API surface) ✅
- No new `BaseEvent` subclass needed — reuses `DecisionEvent` ✅
- No new EventBus patterns — reuses `intelligence.decision` pattern ✅

### 4.2 `src/intelligence/candle/candle_fetcher.py`

**Purpose:** Fetch last N OHLCV candles for a symbol. Self-caching with 10-min TTL.

**Class:** `CandleFetcher`

**Constructor:**
```python
def __init__(
    self,
    interval: str = "5m",      # yfinance interval: "1m","5m","15m","1h"
    n_candles: int = 50,        # how many candles to fetch
    ttl_seconds: float = 600.0, # 10-minute cache
) -> None
```

**Public method:**
```python
def fetch(self, symbol: str) -> list[dict]:
    """
    Returns list of dicts, each with keys:
      open, high, low, close, volume, timestamp (ISO string)
    Returns cached result if within TTL.
    Returns [] on any error (caller must handle empty list).
    """
```

**Internal:**
- Uses `yf.Ticker(symbol).history(period="1d", interval=self._interval)` — NOT `yf.download`
- Cache: `dict[str, tuple[list[dict], float]]` — symbol → (candles, fetched_at_monotonic)
- On error: logs WARNING, returns `[]`
- No imports from any other project layer

### 4.3 `src/intelligence/candle/candle_features.py`

**Purpose:** Pure function — takes raw OHLCV candle list, returns feature dict for the model.

**No class needed** — module-level function only:

```python
def extract(candles: list[dict]) -> dict[str, float]:
    """
    Input: list of OHLCV dicts (open/high/low/close/volume)
    Output: flat dict of float features

    Features computed:
      body_size_mean        — mean abs(close - open) / open
      body_size_last        — last candle body size
      upper_wick_mean       — mean (high - max(open,close)) / open
      lower_wick_mean       — mean (min(open,close) - low) / open
      close_above_open_pct  — fraction of candles where close > open (bullish)
      momentum_3            — (close[-1] - close[-4]) / close[-4] * 100
      momentum_10           — (close[-1] - close[-11]) / close[-11] * 100
      volume_trend          — mean(volume[-5:]) / mean(volume[-20:]) if enough candles
      engulfing_bullish     — 1.0 if last candle engulfs previous bearish candle, else 0.0
      engulfing_bearish     — 1.0 if last candle engulfs previous bullish candle, else 0.0
      doji_last             — 1.0 if last candle body < 10% of range, else 0.0
      high_low_range_pct    — (high[-1] - low[-1]) / close[-1] * 100
    """
```

**Rules:**
- Returns `{}` if `candles` has fewer than 11 entries (not enough for momentum_10)
- All values are `float`
- Pure — no I/O, no imports from any project layer
- No class, no state

### 4.4 `src/intelligence/candle/pretrained_model.py`

**Purpose:** Load a serialized sklearn model and run inference.

**Class:** `PretrainedCandleModel`

**Constructor:**
```python
def __init__(self, model_path: str | Path = "models/candle_rf.pkl") -> None:
    """
    Loads the model from disk on construction.
    If file not found: sets self._model = None, logs WARNING.
    Uses Path(model_path).resolve() — path traversal safe.
    """
```

**Public method:**
```python
def predict(self, features: dict[str, float]) -> tuple[str, float]:
    """
    Returns (signal, probability) where:
      signal: "BUY" | "SELL" | "HOLD"
      probability: float in [0.0, 1.0]

    If model not loaded or features empty: returns ("HOLD", 0.0)
    Feature order is fixed — defined by FEATURE_NAMES class variable.
    """
```

**Class variable:**
```python
FEATURE_NAMES: ClassVar[list[str]] = [
    "body_size_mean", "body_size_last", "upper_wick_mean", "lower_wick_mean",
    "close_above_open_pct", "momentum_3", "momentum_10", "volume_trend",
    "engulfing_bullish", "engulfing_bearish", "doji_last", "high_low_range_pct",
]
```

**Rules:**
- `import sklearn` inside `__init__` — so system works without sklearn installed (just returns HOLD)
- Uses `pickle.load` with `Path.resolve()` guard
- `predict()` builds a numpy array in `FEATURE_NAMES` order, calls `model.predict_proba()`
- Returns the class with highest probability and its probability score
- Class labels assumed: `["BUY", "HOLD", "SELL"]` — sorted alphabetically (sklearn default)

### 4.5 `src/intelligence/candle/candle_strategy.py`

**Purpose:** Orchestrator. Ties together fetcher → features → model → Ollama reviewer → `Decision`.

**Class:** `CandleStrategy`

**Constructor:**
```python
def __init__(
    self,
    ollama_host: str = "http://localhost:11434",
    ollama_model: str = "llama3.1:8b",
    ollama_timeout: float = 30.0,
    model_path: str | Path = "models/candle_rf.pkl",
    interval: str = "5m",
    n_candles: int = 50,
    ttl_seconds: float = 600.0,   # 10-min TTL — same value used by CandleFetcher
    min_model_confidence: float = 0.55,  # below this, skip Ollama and return HOLD
) -> None
```

**Imports (internal only):**
```python
from intelligence.candle.candle_fetcher import CandleFetcher
from intelligence.candle.candle_features import extract as extract_candle_features
from intelligence.candle.pretrained_model import PretrainedCandleModel
from intelligence.agent.ollama_client import OllamaClient   # REUSE existing client
from intelligence.models.decision import Decision
```

**Public method:**
```python
def evaluate(self, symbol: str) -> Decision:
    """
    Full pipeline:
      1. CandleFetcher.fetch(symbol) → candles
      2. extract_candle_features(candles) → features
      3. PretrainedCandleModel.predict(features) → (signal, prob)
      4. If prob < min_model_confidence → return HOLD Decision immediately
      5. OllamaClient.complete(review_prompt) → ollama_response
      6. Parse ollama_response → final action + confidence
      7. Return Decision

    strategy_id = "candle-cil-v1"
    Falls back to HOLD at every step on any exception.
    """
```

**Ollama reviewer prompt structure:**
```
You are reviewing a pretrained ML model's trading signal.

Symbol: {symbol}
Candle interval: 5m, last 50 candles

Pretrained model signal: {signal} (confidence: {prob:.0%})

Candle summary:
- Momentum (3-candle): {momentum_3:+.2f}%
- Momentum (10-candle): {momentum_10:+.2f}%
- Bullish candles: {close_above_open_pct:.0%} of last 50
- Last candle body: {body_size_last:.3f}
- Volume trend: {volume_trend:.2f}x recent vs baseline
- Engulfing bullish: {engulfing_bullish}
- Engulfing bearish: {engulfing_bearish}
- Doji (indecision): {doji_last}

Your job: Review the model's signal. You may CONFIRM, OVERRIDE, or ABSTAIN.
- CONFIRM: you agree with the model signal
- OVERRIDE: you disagree — state your action instead
- ABSTAIN: insufficient evidence — output HOLD

Respond with ONLY this JSON:
{"action": "BUY"|"SELL"|"HOLD", "confidence": 0.0-1.0, "rationale": "1 sentence"}
```

**Decision fusion logic:**
- If Ollama agrees with model → use Ollama confidence (more calibrated)
- If Ollama overrides → use Ollama action + confidence, but cap confidence at 0.70 (override penalty)
- If Ollama abstains (HOLD) → return HOLD
- If Ollama call fails → use pretrained model signal directly with `prob` as confidence

**strategy_id:** `"candle-cil-v1"`

### 4.6 `scripts/train_candle_model.py`

**Purpose:** One-time script to train and serialize the RandomForest model.

**What it does:**
1. Fetches 60 days of 5m candle history for all 6 symbols via yfinance
2. Computes `candle_features.extract()` on rolling 50-candle windows
3. Labels each window: BUY if price +1% in next 3 candles, SELL if -1%, else HOLD
4. Trains `RandomForestClassifier(n_estimators=100, max_depth=6, random_state=42)`
5. Saves to `models/candle_rf.pkl` via `pickle.dump`
6. Prints classification report

**Run once:**
```bash
python scripts/train_candle_model.py
```

## 7. Fallback chain (every step is safe)

```
CandleFetcher fails          → returns []
extract_candle_features([])  → returns {}
PretrainedModel.predict({})  → returns ("HOLD", 0.0)
prob < min_model_confidence  → returns HOLD Decision immediately
OllamaClient fails           → uses pretrained signal directly
JSON parse fails             → returns HOLD Decision
Any unhandled exception      → returns HOLD Decision
```

No exception ever propagates out of `CandleStrategy.evaluate()`.
